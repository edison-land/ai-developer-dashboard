# v0.9.0 发布检查表：网页与 CLI 阶段

> 归属：v0.9.0 · UI 回归保护
>
> 状态：历史阶段资料。它记录当时的网页/CLI 发布验证，不适用于后续 Windows 安装包交付；桌面版请使用[桌面版使用、调试与交付指南](../../desktop-usage-and-delivery.md)。

这份清单把自动验证、真实模型验证和人工视觉验证分开，避免把“测试通过”误认为“真实环境全部通过”。

## 自动验证

- [ ] `pnpm typecheck`
- [ ] `pnpm test`（包含 core、server 和 UI 测试）
- [ ] `pnpm build:ui`
- [ ] `pnpm verify:ui-redesign`
- [ ] `git diff --check`

## 真实模型验证

- [ ] 本机设置中已配置智谱 Key
- [ ] `pnpm smoke:synth` 成功
- [ ] 记录执行日期、provider、实际模型、选中项目数、输入/输出 token 和失败数量
- [ ] 首次总结成功，输出符合 schema
- [ ] 同一项目第二次调用命中缓存
- [ ] 2500 token 输入上限被严格执行
- [ ] 日志和输出中没有 API Key 或完整 transcript

## 浏览器人工验证

- [ ] `pnpm start` 正常启动并打开本机网页
- [ ] 今日页显示最多三个重点，置顶、排序和当天移除有效
- [ ] 项目页搜索、来源 OR 筛选、时间筛选和列表/阶段视图有效
- [ ] 详情弹窗可改阶段、恢复自动判断、归档和关闭
- [ ] 归档抽屉可以查看并恢复项目
- [ ] 批量总结显示 `X/总数`，逐项结果即时更新，单项失败后继续
- [ ] 暖白与深墨主题文字清晰
- [ ] 1024 像素宽度没有整页横向溢出
- [ ] 浏览器控制台没有错误

## 异常场景

- [ ] 无 API Key 时页面仍可刷新和浏览项目
- [ ] Claude Code 或 Codex 数据源不存在时页面仍可打开
- [ ] 端口占用时终端给出换端口提示
- [ ] 服务端错误和异常响应会显示可操作的错误信息
- [ ] 数据库已有旧表时可以正常启动
