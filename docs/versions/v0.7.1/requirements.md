# v0.7.1 需求：重点信号与来源展示完善

> 阶段目标：让用户更容易理解“为什么这个项目是重点”以及项目状态来自哪里。

## 需求范围

1. 人工置顶的重点卡需要明显但克制的置顶标记。
2. 屏幕阅读名称需要说明项目是否已置顶。
3. Claude Code、Codex 和 Git 使用各自可识别的来源标志。
4. Codex 标志适配明暗主题。
5. 项目详情从容易遮挡内容的侧边形态调整为更适合集中阅读的弹窗。
6. 项目没有会话活跃时间时，使用 Git 最近提交时间作为活跃度兜底。

## 验收标准

- 置顶状态不只依靠排序表达。
- 来源图标在浅色和深色主题下清楚可见。
- 详情弹窗支持遮罩关闭和 Escape。
- Git-only 活跃依据不会被错误显示为从未活动。
- 新增兜底逻辑有聚合测试。

## 本版本不做

- 改变今日重点推荐顺序；
- 新增数据源；
- 修改 AI 提示；
- 接入新的模型 provider。
