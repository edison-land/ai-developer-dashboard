# v0.5.0 需求：日常工作流补齐

> 阶段目标：让项目越来越多时仍能快速筛选、隐藏和回顾最近变化。

## 1. 最近动态

- 合并 Claude Code、Codex 和 Git 的近期动作。
- 按时间倒序，最多保留 100 项。
- 使用已采集的项目数据生成，不额外扫描或启动 Git。
- 提供加载、空数据和错误状态。
- 归档项目不出现在动态中。

## 2. 自动机械刷新

- 设置刷新分钟数，`0` 表示关闭。
- 到时间后调用机械刷新，重新采集本地项目。
- 刷新后同步更新项目、健康状态和活动流。
- 本版本只做机械刷新，不自动调用 AI。

## 3. 来源与时间筛选

- 来源包含 Claude Code、Codex、Git。
- 来源多选使用 OR：具备任一选中来源即命中。
- 时间档为全部、今天、本周、本月、更早。
- 来源和时间之间使用 AND。
- 筛选状态保存在当前浏览器。

## 4. 归档

- 项目可以归档并从项目页、今日视图和活动流隐藏。
- 归档状态按 canonical path 持久保存。
- 新活动不会自动解除归档，只能手动恢复。
- 查看归档时可以恢复项目。

## 5. 阶段列悬停展开（本版本原需求）

- 默认显示紧凑卡。
- 鼠标进入一列时，只展开该列并显示完整卡片。
- 使用覆盖式浮层，不能推动其他列或造成页面抖动。
- 最左和最右列向视口内部展开。
- 按当时确认范围，不提供触屏或键盘等价操作。

## 6. 视觉与可读性

- 提升卡片层次和文字对比度。
- 最小字号不低于 11px。
- 数字使用等宽数字表现。
- 支持 `prefers-reduced-motion`。
- 设置表单、错误提示和筛选状态补充必要语义。

## 验收标准

1. 活动流按时间正确合并三源事件。
2. 自动机械刷新可开关。
3. 筛选组合与持久化正确。
4. 归档、隐藏、包含归档查询和恢复形成完整闭环。
5. 悬停展开不造成整页 reflow。
6. 类型检查、自动测试和 UI 构建不增加错误。

## 本版本不做

- Electron；
- 自动刷新时 AI 总结；
- 云同步；
- 全面重做信息架构。
