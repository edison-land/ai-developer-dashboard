# v1.0.0 需求：桌面入口迁移

> 状态：✅ 已完成，验收记录见 `completion.md`
> 设计批准日期：2026-08-01
> 阶段目标：把现有“CLI 启动后在浏览器使用”的入口，迁移成可直接双击的 Windows 独立软件。

## 用户结果

完成本阶段后，项目所有者可以解压软件并直接双击使用，不再需要打开终端、启动 CLI、访问浏览器地址或处理端口。

## 范围

- 提供可双击运行的 Windows 免安装测试版。
- 使用薄桌面外壳承载现有前端，页面、展示内容和交互行为保持不变。
- 复用现有 `packages/core`、`packages/server` 和 `packages/ui`，不重写业务逻辑。
- 软件自行启动和停止本地后端，并自动选择内部可用地址。
- 只允许一个桌面实例；重复双击时唤醒并置前现有窗口。
- 关闭桌面窗口时完全退出，并停止软件自己启动的后端。
- 自动承接现有项目阶段、归档、今日重点、AI 总结缓存和模型配置。
- `apps/cli` 不再面向普通用户，仅暂时保留为内部开发、测试和诊断工具。

## 验收标准

1. 解压免安装测试版后，可以通过双击直接打开软件。
2. 启动过程不要求终端、浏览器或手动端口配置。
3. 软件窗口中的页面、展示内容和主要交互与现有网页版本一致。
4. 现有数据和配置可以直接继续使用，不要求重新设置或手动复制数据库。
5. 重复双击不会启动第二个窗口或第二套后端，而是唤醒现有窗口。
6. 关闭窗口后，软件及其负责的后端完全退出；再次双击可以正常重新启动。
7. 现有网页业务逻辑和核心自动化验收不因入口迁移而改变。

## 本版本不做

- 正式安装、覆盖升级、卸载和重装；这些属于 v1.1.0。
- 面向外部测试者的发布准备；这些属于 v1.2.0。
- 修改页面结构、展示内容、交互流程或业务逻辑。
- 系统托盘、开机启动、后台常驻和自动更新。
- 云同步、多用户和自动上传日志。
- 正式公开发布。
