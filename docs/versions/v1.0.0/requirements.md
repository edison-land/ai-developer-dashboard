# v1.0.0 需求：Electron 桌面产品化

> 状态：⏸️ 暂缓
> 阶段目标：在用户确认桌面形态有价值后，把已稳定的本地网页封装为可安装的 Windows 应用。

## 决策门槛

本版本不会自动开始。需要先确认：

- CLI + 浏览器是否已经不能满足日常使用；
- v0.8.0、v0.9.0 已完成；
- 本地试用证明核心工作流稳定；
- 用户愿意承担安装包、升级和桌面兼容的长期维护成本。

## 计划范围

### 桌面壳

- Electron 主进程复用现有 `packages/server` 和 `packages/core`。
- 启动本机服务并加载本地 URL，不重写数据采集。
- 单实例运行，避免重复端口和数据库竞争。

### Windows 交付

- 生成 Windows 安装包。
- 明确应用数据目录和迁移策略。
- 支持首次安装、覆盖升级和卸载。
- 卸载默认不删除用户数据库，除非用户明确选择。

### 运行保护

- 检查端口占用、数据库不可写和数据源不可用。
- 主进程和服务端错误提供可读诊断。
- 不在渲染进程暴露 Node 或密钥。

## 验收标准

1. 干净 Windows 环境可以安装并启动。
2. 现有本地项目数据能够正常读取。
3. 升级后设置、归档、阶段和总结缓存保留。
4. 卸载与重装的数据保留规则符合说明。
5. 网页版统一验收继续通过。
6. Electron 专项启动、升级和安全检查通过。

## 本版本不做

- 云端同步；
- 多用户；
- 自动上传日志；
- 重写 core 或 server；
- 在用户确认前开始实现。
