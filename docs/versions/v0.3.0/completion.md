# v0.3.0 完成情况：AI 总结与成本控制

> 状态：✅ 已完成（智谱范围）
> 完成日期：2026-07-28
> 主要提交：`c39a2e0`

## 实际完成

- 新增有界 bundle、输出 schema、输入哈希和总结编排。
- 新增智谱 OpenAI-compatible provider。
- JSONL 只读取最后 256 KB，再从中选择少量有效内容。
- 新增单项目与批量总结接口、项目卡总结按钮和 stale 提示。
- 新增 `scripts/smoke-synth.ts` 真实模型冒烟入口。
- 密钥继续由本机 SQLite 保存，接口不回显明文。

## 模型调整

- 早期尝试的 `glm-4.7-flash` / `glm-4.5-flash` 会把 token 用在推理内容，主内容可能为空。
- 最终改为非推理 `glm-4-flash-250414`。
- 部分 flash 模型不接受 `response_format`，因此使用系统提示 + 鲁棒 JSON 提取。

## 验证记录

- 缓存命中、失败降级、无效 JSON、输入截断和 schema 均有自动测试。
- 服务端测试覆盖单项目与批量接口。
- 历史阶段记录为 81 项测试通过。

## 已知缺口

- 运行时只有智谱 provider；Anthropic/OpenAI 尚未接入。
- `synth_on_refresh` 可以保存，但没有接入刷新流程。
- 冒烟脚本的成本提示仍含旧模型名，输入超限目前只警告。
- 批量总结最初只能等待整批结果，逐项进度在 v0.7.0 补齐。

以上“能力名实一致”和真实冒烟问题统一归入 v0.8.0。
