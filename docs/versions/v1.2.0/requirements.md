# v1.2.0 需求：首位外部测试者交付

> 状态：🟡 内部交付准备完成，等待首位外部测试者
> 设计批准日期：2026-08-01
> 阶段目标：让第一位不参与开发的人能够拿到软件，并按照说明独立完成安装、启动和基本使用。

## 用户结果

完成本阶段后，首位外部测试者不需要了解仓库、CLI 或端口，也能识别正确安装包、完成安装并进入现有数据页面；遇到启动问题时知道如何反馈或恢复。

## 启动条件

- v1.1.0 已完成安装、升级、卸载和数据保留验收。
- 已确定首位外部测试者和可用于真实验收的 Windows 环境。

## 范围

- 提供带明确版本号的安装包。
- 提供简短的安装、启动和卸载说明。
- 在一台干净的 Windows 电脑上完成真实验收。
- 软件启动失败时给出可以理解的提示，不能无声退出。
- 记录已知限制、数据保留规则和恢复办法。
- 明确安装包来源并提供完整性核对方式，避免测试者使用错误文件。
- 记录首位测试者能否独立完成安装、启动和基本使用。

## 验收标准

1. 首位外部测试者可以识别正确版本的安装包。
2. 测试者按照说明完成安装和启动，不需要终端、浏览器或端口操作。
3. 软件显示与现有版本相同的页面和业务内容。
4. 启动失败时有可理解的提示，并能按说明反馈或恢复。
5. 在干净 Windows 环境完成一次真实安装、启动和卸载验收。
6. 已记录测试结果、已知限制和后续需要解决的问题。

## 本版本不做

- 修改页面、展示内容或业务逻辑。
- 正式公开发布。
- 自动更新。
- 付费代码签名的强制要求。
- 大规模 Windows 兼容承诺。
- 云同步、多用户和自动上传日志。
