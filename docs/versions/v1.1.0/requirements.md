# v1.1.0 需求：安装与数据管理

> 状态：✅ 已完成，验收记录见 `completion.md`
> 设计批准日期：2026-08-01
> 阶段目标：把 v1.0.0 的免安装测试版升级成可以长期安装、升级和卸载的 Windows 软件。

## 用户结果

完成本阶段后，项目所有者可以像使用普通 Windows 软件一样安装、启动、升级、卸载和重装，原有个人数据不会意外丢失。

## 启动条件

- v1.0.0 已完成并通过免安装独立软件验收。
- v1.0.0 的页面、业务逻辑和数据读取没有因桌面入口迁移出现回归。

## 范围

- 提供正式的 Windows 安装包。
- 安装后可以从桌面或开始菜单启动软件。
- 自动承接旧 CLI 和 v1.0.0 免安装版使用的数据。
- 覆盖升级后保留项目状态、归档、今日重点、AI 总结缓存和模型配置。
- 卸载默认保留个人数据，重新安装后可以继续使用。
- 如果需要调整数据存放位置，由程序自动迁移并保留可恢复的备份。

## 验收标准

1. 可以完成首次安装，并从 Windows 常用入口启动软件。
2. 安装后仍显示与 v1.0.0 相同的页面和业务内容。
3. 旧 CLI 和免安装版产生的数据可以自动继续使用。
4. 覆盖升级后，设置、归档、阶段、今日重点和总结缓存保持不变。
5. 默认卸载不会删除个人数据；重新安装后可以恢复使用。
6. 如果发生数据迁移，用户不需要手动复制文件，并存在可恢复备份。

## 本版本不做

- 修改页面、展示内容或业务逻辑。
- 自动更新。
- 正式公开发布或大规模 Windows 兼容支持。
- 把付费代码签名作为完成条件。
- 云同步、多用户和自动上传日志。
